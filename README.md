# Dinesh Behera — Research Portfolio Website

This website was rebuilt from the information in the supplied CV.

## Files

- `index.html` — website content and structure
- `styles.css` — layout, colours, typography, and responsiveness
- `script.js` — mobile menu and automatic footer year
- `assets/` — profile image, CV, and future research images

## Before publishing

1. Replace `YOUR-USERNAME` in `index.html` with your GitHub username.
2. Add your photograph as:
   `assets/profile.jpg`
3. Add your current CV as:
   `assets/Dinesh-Behera-CV.pdf`
4. Review your email address and LinkedIn URL.
5. Add optional links to Google Scholar, ORCID, publications, and project repositories.

## Publish with GitHub Pages

Create a GitHub repository called:

`YOUR-USERNAME.github.io`

Upload all files from this folder to the repository root.

Then open:

`Settings → Pages → Deploy from a branch → main → / (root)`

Your website will appear at:

`https://YOUR-USERNAME.github.io`

## Preview locally

Open `index.html` directly in your browser, or use the Live Server extension in Visual Studio Code.
